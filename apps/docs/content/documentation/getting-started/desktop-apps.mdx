---
title: Desktop Apps
description: Install Durabull on Apple Silicon macOS or Windows.
---

The desktop app bundles the web UI and a local API. Settings persist in its user-data directory;
you do not need a separately hosted Durabull API.

## Downloads

Choose an asset from the [GitHub releases](https://github.com/durabullhq/durabull/releases/latest):

| Platform | Asset |
| --- | --- |
| Apple Silicon macOS | `Durabull-<version>-arm64.dmg` |
| Windows installer | `Durabull.Setup.<version>.exe` |
| Windows portable | `Durabull-<version>-win.zip` |

### Verify the macOS download

Download the DMG and `durabull-macos-arm64.sha256` **from the same release**, then run this in
the folder containing both files:

```bash
shasum -a 256 -c durabull-macos-arm64.sha256
```

The command should print `OK` for the DMG. If verification fails, discard it and download both
files again from the same release.

### Homebrew (Apple Silicon macOS)

```bash
brew install --cask durabullhq/tap/durabull
```

Homebrew verifies the checksum declared by the cask. If macOS blocks launch, follow the steps below.

## First launch

1. On macOS, mount the verified DMG and drag Durabull to Applications. The current app is unsigned.
   If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway**, or, for a verified
   download you trust, run `xattr -dr com.apple.quarantine /Applications/Durabull.app`.
2. Launch Durabull from Applications on macOS or the Start menu on Windows. For the portable ZIP,
   extract it and launch the executable.
3. Add your Redis connection and open **Queues Dashboard** to confirm queues load.

Continue with [How to Use Durabull](/documentation/getting-started/how-to-use-durabull) or
[Connection Management](/documentation/getting-started/connection-management). For server
hosting, see [Self Hosting Setup](/documentation/self-hosting/setup).
